# dv-flow-lib-hdlsim
Core libray for HDL simulation 

Simulator packages:

- `hdlsim.ivl` - Icarus Verilog
- `hdlsim.mti` - Siemens Questa
- `hdlsim.vcs` - Synopsys VCS
- `hdlsim.vlt` - Verilator
- `hdlsim.xcm` - Cadence Xcelium
- `hdlsim.xsm` - AMD Xilinx Vivado (XSim)
- `hdlsim.xzm` - [xezim](https://github.com/aionhw/xezim)

See `docs/index.rst` for what each one supports.
